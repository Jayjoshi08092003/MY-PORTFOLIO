## 🚀 Key Features

- **Dynamic day/night mode** with animated sun/moon and gradient background
- **Profile and hero section** introducing Jay Joshi
- **Navigation buttons** to Projects, Experience, Skills, Contact, and Resume pages
- **Responsive and modern UI** designed with custom CSS and Bootstrap
- **Contact form** with optional file upload and AES-encrypted messaging
- **Animated effects** based on the time of day

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3, Bootstrap, JavaScript,Mongo Db,Express.js,React.js,MERN.
- **Features:** Theme-switching, animations, responsive design

## 💡 Usage

1. **Clone this repo:**
git clone https://github.com/Jayjoshi08092003/MY-PORTFOLIO.git
cd MY-PORTFOLIO/portfolio-backend


2. **Open `index.html` in your browser**  
- No build step is needed: all dependencies are linked via CDN.
- For contact form backend/API, see `contact.html` description.

3. **Customize content:**  
- Edit `index.html` for your intro/about.
- Edit `projects.html`, `skills.html`, and `experience.html` as needed.
- Replace `resume_research3.docx` to update your CV.

## 🌚 Day/Night Theme

- Switch themes anytime with the **Toggle Theme** button at the top right.
- Background gradients and animations adapt for a unique experience.
